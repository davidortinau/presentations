# The Rise of Xamarin: Mobile Development in C#

**St. Louis ALT.NET** · Professional Employment Group, Saint Louis, USA · Wednesday 28 August 2013, 19:00 · [Session page](http://www.meetup.com/stlaltdotnet/events/133172182/)

## Abstract

> Xamarin empowers us to develop native applications for iOS, Android, Mac and of course Windows and Windows Phone, with a fantastic amount of shared code and resources. We will take a look at the technology fueling this dream, the development workflow, and how viable this solution is for companies from enterprise to independent.
