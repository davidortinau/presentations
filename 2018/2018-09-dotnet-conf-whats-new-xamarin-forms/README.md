# S109 What's New in Xamarin.Forms?

**.NET Conf 2018** · September 2018 · [Session page](https://learn.microsoft.com/en-us/shows/dotnetconf-2018/s109)

[![First slide of S109 What's New in Xamarin.Forms?](thumbnail.jpg)](slides.pdf)

## Abstract

> Xamarin.Forms has long been the best way for .NET developers to build cross-platform applications for Android, iOS, and Windows, and in 2018 it's gotten even better with the introduction of great new capabilities like CSS, FlexLayout, Visual State Manager, and much more. Come learn what's new!

From the [session page](https://learn.microsoft.com/en-us/shows/dotnetconf-2018/s109).
