# The Journey to .NET MAUI GA

**Progress Telerik "Snorkeling in MAUI"** · Online · Wednesday 4 May 2022

## Abstract

> The awesome David Ortinau came to chat about The Journey to .NET MAUI GA. David talked about some of the latest additions in the .NET MAUI stack—the application Shell, Tizen platform support, and recapped how developers can customize the experience on each platform. It's impressive that the .NET MAUI team was able to drop in a full Style guide—for common out-of-the-box UI including visual states, all without much impact to startup performance.
>
> David showed off a few polished sample apps written with .NET MAUI—runtime/tooling is ready and there is plenty of inspiration ahead of GA. Let's dive right in!
