# Getting the Most from .NET MAUI

**Techorama NL 2024** · October 2024

[![First slide of Getting the Most from .NET MAUI](thumbnail.jpg)](slides.pdf)

## Abstract

> .NET MAUI is being used by major companies around the globe to develop business critical applications. At Microsoft we engage with them to learn how they are using .NET MAUI successfully, and what we can be doing to further improve the product. Come learn in this session some of the best practices so you too get can get the most from .NET MAUI when building applications for Android, iOS, macOS, and Windows with C# and Visual Studio.

From the [Sessionize session page](https://sessionize.com/s/david-ortinau/getting-the-most-from-.net-maui/93804).
