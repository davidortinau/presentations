# Comet: A .NET UI Experiment, and Xamarin.Forms Features

**#XamarinSaturday (TO Mobile Devs)** · Toronto, Canada · September 2019

## Abstract

> C# is beloved. .NET is beloved. Visual Studio is beloved. Productivity is… beloved. What might the next iteration of a cross-platform UI framework look like for .NET developers that want to reach mobile, desktop, web, and… well, all the places that .NET runs? Let’s look at one such experiment to try it on for size.
>
> Xamarin is a maturing, powerful, and extremely flexible set of .NET technologies that you are not using to its full potential. By understanding the rules of this universe, your eyes will be opened to the incredible possibilities for your companies and your customers. It’s one thing to share more code, but how might you share more .NET code to your Swift, Obj-C, Java, Kotlin coworkers? And what about UI in this ever increasing market of devices and operating systems?
