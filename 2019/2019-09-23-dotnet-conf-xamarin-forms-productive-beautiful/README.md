# Xamarin.Forms: More Productive and Beautiful Than Ever

**.NET Conf 2019** · Online · Monday 23 September 2019 · [Session page](https://learn.microsoft.com/en-us/shows/dotnetconf-2019/xamarinforms-more-productive-and-beautiful-than-ever)

[![First slide of Xamarin.Forms: More Productive and Beautiful Than Ever](thumbnail.jpg)](slides.pdf)

## Abstract

> Xamarin.Forms continues to add features to help you more quickly build beautiful cross-platform mobile apps using C#, .NET, and Visual Studio. Discover the power and productivity of new features such as Shell and Visual, and new controls like CollectionView, CarouselView, and many others.

From the [Microsoft Learn show page](https://learn.microsoft.com/en-us/shows/dotnetconf-2019/xamarinforms-more-productive-and-beautiful-than-ever).
