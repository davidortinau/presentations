# Crafting Consistent Designs with Xamarin Forms Featuring Microsoft PM David Ortinau [Webinar]

**Syncfusion webinar** · Online · April 2019

## Abstract

> Xamarin.Forms 3.6 introduces Visual, a new way to easily unify the look and feel of your cross-platform applications. The first design system supported by Visual uses Google's Material Design system for Android and iOS. In this session we'll showcase all the beautiful controls you can now use with Material, and demonstrate how you can create your own Visual enabled renderers.
