# Creating Consistent UI with Xamarin.Forms Visual

**Xamarin Developer Summit 2019** · Houston, United States · July 2019 · [Session page](https://learn.microsoft.com/en-us/shows/xamarin-xamarin-developer-summit-2019/creating-consistent-ui-with-xamarinforms-visual)

[![First slide of Creating Consistent UI with Xamarin.Forms Visual](thumbnail.jpg)](slides.pdf)

## Abstract

> More and more companies and designers expect mostly or exactly the same design experience across Android and iOS. A combination of styles, effects, behaviors, and platform renderers can get you there, but what if instead of unifying platform differences you could start with a common experience? Visual provides consistent styling and behavior so you can focus more on building the rest of your application. In this session we'll demonstrate how to use the new Material Visual now shipping, and how you can create, package, and consume your own design system.

From the [session page](https://learn.microsoft.com/en-us/shows/xamarin-xamarin-developer-summit-2019/creating-consistent-ui-with-xamarinforms-visual).
