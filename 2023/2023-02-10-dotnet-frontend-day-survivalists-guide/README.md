# A Survivalist's Guide to .NET MAUI

**.NET Frontend Day 2023** · Epicenter, Stockholm, Sweden · Friday 10 February 2023

[![First slide of A Survivalist's Guide to .NET MAUI](thumbnail.jpg)](slides.pdf)

## Abstract

> Whether you are starting a new app or upgrading from Xamarin, I'll share some insights to make your apps better and tips to save you time along the way. Come learn about .NET workloads, layouts, upgrading, single project, C# hot reload, and more.

From the [Official .NET Frontend Day video description (Dotnet Frontend Day channel)](https://www.youtube.com/watch?v=EoERm4ey96M).
